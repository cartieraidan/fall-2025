# Milestone 5

## Feature 1
### Explanation:
Implementation of images into Uno game. All Card classes are associated with a ``.png`` filename
by its type and colour. And for the background and buttons we manually update the view.

### Implementation:
* In Card class in the method `getFileName()`
* In GameManager class in methods `displayHand()` & `updateDiscardPile()`
* In UnoView class in methods `addControlButtons()` & `UnoView()`
